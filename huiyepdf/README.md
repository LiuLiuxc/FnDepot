# 汇页 PDF

**PDF 与扫描件的合并 / 拆分 / 压缩 / 水印工具**（飞牛 fnOS 第三方应用 · 当前包版本：1.0.29）

> 全部处理都在你自己的浏览器与 NAS 本机之间完成：**文件不上传任何外部服务器**。
> 装完即用，不需要额外依赖、不需要注册账号。

---

## 这是什么

把合同、发票、扫描件、手机拍的照片一起丢进来，按你要的顺序整理成一份（或几份）PDF：合并、排序、删页、旋转、压缩、打水印，一次做完。

适合：手里有一堆 PDF 和扫描图，需要合成一份交出去；或者一份大文件要拆成几份分别归档；或者外发前需要压上"仅用于办理 XX 业务使用"的水印。

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 合并 | PDF 与图片（JPG / PNG / WEBP / BMP）可以混着拖进来，按卡片顺序合并 |
| 排序 | 拖动卡片，或用卡片上的上下箭头调整顺序 |
| 删页 / 旋转 | 每一页都能单独删除、旋转 90° |
| 逐页预览 | 导出前先看最终效果（含水印）；滚到哪渲染到哪，几十页也是秒开 |
| 按页拆分 | 一份文件按页码范围拆成多份：`1-3` 连续、`4,6` 跳页都行；每份单独命名，一次存盘 |
| 压缩导出 | 页面栅格化为 JPEG 再合成，质量 40-90%、分辨率 120 / 150 / 200 DPI 可调 |
| 隐私水印 | 全屏平铺的用途声明，文字 / 字体 / 字号 / 颜色 / 透明度 / 密度 / 角度都可调，设置面板里就能看到真实效果 |
| 保存位置 | 存到 NAS 上任意已授权的文件夹；也可下载到本机 |

> 手机上的飞牛 App 里请用「保存到 NAS」，保存后在飞牛「文件」里选中该文件点「下载」即可存到手机——这是飞牛自己的下载通道，网页端下载会被 App 丢弃。

## 隐私与数据

- **处理位置**：合并、排序、旋转、压缩、加水印、拆分、生成 PDF 全部在你的浏览器内完成；NAS 端只负责提供页面和「把生成好的文件写到你选的位置」。
- **不联网**：不引入任何统计、广告或第三方请求。
- **只写你选的地方**：不会碰你没有授权的目录；未授权任何文件夹时，默认保存到应用共享目录。
- **同意记录**：首次打开会显示《用户协议与隐私说明》，同意状态记录在 `var/consent.json`；卸载重装会重新征求同意。
- **输入文件**：请只导入来源正规、内容合法的文件；导入伪装/畸形文件导致的异常由使用者自行承担（详见应用内协议 7.5–7.8）。

## 系统要求

- 飞牛 fnOS **1.2.0** 及以上
- 平台：**x86_64 / arm64 通用**（同一个包）
- 浏览器：任意现代浏览器（Chrome / Edge / Safari / 飞牛桌面与 App 内置浏览器）
