# miNVR · Anixc 的 FnDepot 应用源

**miNVR** · 适配米家摄像头的本地视频监控（飞牛 fnOS 第三方应用 · 当前包版本：1.4.68）

> **添加本源**：Moo → 设置 → 应用源设置 → 添加 `https://github.com/LiuLiuxc/FnDepot`
>
> 本仓同时服务两个生态，一份内容两个索引：`moo.json`（Moo 客户端）、`fnpack.json`（FnDepot 生态）。安装包挂在本仓的 Release 里。

> **说明**：本应用为个人开发者作品，基础功能长期可用；需要完整能力时，**请与开发者联系**（应用内「图腾」处提供开发者邮箱），按设备获取 1 枚图腾后填入即可启用，**一机一码**、永久有效。**获取图腾后**享完整功能：事件时间轴标记、邮件变动推送带图 / 「仅有人」/ 打包汇总、录像按 1/3/6 个月或 1/2/3 年长期保存、高级侦测与存储设置可调。**未获取图腾（含 15 天免费试用结束后）**：画面预览、本地录像、故障邮件等基础功能仍可用，录像约 15 天滚动存储、历史可回放近 15 天、实时事件仅显示最近 3 条、变动推送不附截图。新装自动赠送 **15 天全功能试用**。

---

## 这是什么

把已有米家摄像头的画面，接到自己的飞牛 NAS 上做**本地监控**：实时预览、区域侦测、事件录像、历史回放、邮件提醒。

适合：家里/店里已经有米家摄像头，希望画面**留在 NAS 本地**，而不是再买一套通用 NVR 的用户。

录像与配置保存在本机，**不经第三方云存储平台**。

---

## 核心能力

| 功能 | 说明 |
|------|------|
| 实时预览 | 浏览器或飞牛桌面小窗查看画面 |
| 区域标定 | 框选识别区，只对区内变动告警/录像 |
| 事件录像 | 预录 + 变动过程 + 结束后延；后延期间又有变动会自动顺延，可续录 |
| 历史回放 | 按天时间轴，录像段与事件标记清晰 |
| 邮件提醒 | 故障必达；变动可附截图；支持免打扰；到期提醒可关 |
| 本地存储 | 录像保存在本机，不经第三方云存储 |
| 设备范围 | 米家账号下可直连取流的**摄像头**产品；门锁猫眼、门铃、喂食器这类按需唤醒设备不提供常驻视频流，列表中不再列出 |

> **录像声音**：1.3.57 起支持录音，**默认关闭**。请在设置页打开「连续录像录音」与/或「事件片段录音」后，连续录像与事件片段才会带音轨。

## 数据与图腾

- 录像目录：应用中心 → miNVR → 应用设置 → **运行设置**
- **更换录像目录后**：图腾可能失效（图腾信息跟随应用配置，与录像目录无关）；若提示图腾失效，到「系统设置 → 添加摄像头」重新完成取流授权即可
- 登录：飞牛 NAS 账号，或应用内账号（用户名+密码）
- 图腾：一机一码（1 枚图腾对应 1 台设备，永久有效）；基础功能长期可用；获取图腾请联系开发者
- **未获取图腾/试用结束**：录像约 15 天滚动、回放近 15 天；可推故障与画面变动（不附截图、无「仅有人」）；免打扰为独立全局开关；图腾到期提醒与文件删除前备份各自独立设置
- 协议：首次启动需同意《最终用户许可协议与免责声明》
